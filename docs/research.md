# Public research map

Public availability does not imply redistribution rights. The model and fictional data are original. The links provide the source material.

| Discipline | Public source | Product translation |
|---|---|---|
| FMVA | [CFI curriculum](https://corporatefinanceinstitute.com/certifications/financial-modeling-valuation-analyst-fmva-program/) | Linked forecasts, DCF, comparable companies, sensitivity and valuation communication. |
| Intrinsic valuation | [Damodaran, NYU Stern](https://pages.stern.nyu.edu/adamodar/pdfiles/eqnotes/dcfall2pg.pdf) | Match FCFF to WACC and bridge enterprise value to equity. Add FCFE, APV, country-risk calibration and distressed valuation separately. |
| Economic returns | [Mauboussin and Callahan](https://www.morganstanley.com/im/publication/insights/articles/article_returnoninvestedcapital.pdf) | Connect terminal growth to reinvestment and return on new capital. |
| Professional valuation | [IVSC and IVS 200](https://ivsc.org/standards/) | Document purpose, valuation basis, assumptions, evidence and reporting. Formal standards mapping is future work. |
| CFP | [FPSB practice standards](https://www.fpsb.org/wp-content/uploads/2021/03/210208_doc_PracticeStandards_FINAL_PDF.pdf) | Keep investment valuation separate from suitability and client goals. Build South African planning rules separately. |
| Auditing | [IAASB ISA 540](https://www.iaasb.org/focus-areas/auditing-accounting-estimates) | Challenge evidence, methods and assumptions. Reconciliations are implemented. Independent estimate ranges, cutoff testing, anomaly review and sign-off are future work. |
| ESG | [IFRS Foundation ISSB overview](https://www.ifrs.org/sustainability/knowledge-hub/faqs/) | Map material disclosures to business drivers, timing and evidence. |
| Actuarial methods | [ASOP 56](https://www.actuarialstandardsboard.org/asops/modeling-3/) | Apply model governance and validation. Probability calibration, correlation, seeded simulation and liability valuation remain future work. |
| Market and data analysis | [SEC EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) | Future adapter should preserve filing date, period, currency, units and restatements. Start with a reviewer-approved mapping before adding automatic peer and local market data. |
| Agent integration | [MCP Python SDK](https://py.sdk.modelcontextprotocol.io/) | Use the same typed case and deterministic calculations across interfaces. |
